Selected work

Three projects, in depth

Tactical Drone GCS Simulator

Delivered

A multi-screen ground control station for tactical drone operations — live telemetry visualisation and flight-mode state machines, giving operators full situational awareness without any physical flight hardware.

  • Unity
  • C#
  • Telemetry
  • State machines

UAS simulation engine

162 tests

A from-scratch tactical UAS simulation engine: WGS-84 geodesy, GNSS and INS modelling with a graded fix ladder, RF propagation with terrain masking, and protocol-conformant KLV, CoT and DIS output that real tooling ingests.

  • Python
  • MISB ST 0601
  • IEEE 1278 DIS
  • GNSS / INS

VR flood simulation

In development

Real terrain captured by photogrammetry, flooded by a solver rather than an animation. Combines a Lattice Boltzmann fluid implementation with real-world capture and a VR frame budget — the visuals and the physics come from the same project.

  • Unity
  • COLMAP
  • Open3D
  • LBM / CFD

How we work

What happens after you email

  1. 1

    Scoping call — free, 30 minutes

    What you need, what's technically possible, and roughly what it costs. If we're not the right fit, we'll say so on this call.

  2. 2

    Written proposal

    Fixed scope, fixed price, milestone dates. No hourly surprises.

  3. 3

    Build in milestones

    A working build at each milestone, not a status email. You see progress you can run yourself.

  4. 4

    Handover

    Source, documentation, and a walkthrough session. You own everything.

NDA before the first call if you need one. You own all IP on delivery.

About

Deliberately small

Aerovant is a simulation and XR engineering practice led by Rahul Kumar, an engineer at IIT Mandi working across computer graphics, applied physics, and low-latency systems.

The work sits where most studios split in two: real-time 3D that looks right, and the physics and systems engineering that makes it behave right. Recent projects include a delivered ground-control-station training simulator, an XR digital-twin platform, and photogrammetry pipelines built on COLMAP and Open3D.

You work directly with the engineer building your project — no account managers, no handoffs.
